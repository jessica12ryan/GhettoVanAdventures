# Social queue — append-only log of X / Instagram posts to feature as feed cards.
#
# One post per line:
#   source | url | date | title [| excerpt]
#
#   - X lines need only the URL: text, date and thumbnail are resolved
#     automatically (no API key). Add date/title only as a fallback.
#       x | https://x.com/ghetto_van/status/1234567890
#   - Instagram serves nothing to unauthenticated requests, so IG lines
#     must include date and title by hand:
#       instagram | https://www.instagram.com/ghettovanadventures/p/ABC123/ | 2026-10-08 | Camp sunset
#
# Lines starting with # and blank lines are ignored. Never delete lines:
# the importer upserts by URL-derived id, so re-running is harmless.
# Run hourly via .github/workflows/update-posts.yml (tools/apply-queue.py).
